# ChatApp – Modern Messaging Application UI
---

A modern, clean, and responsive messaging application interface designed to provide a smooth and user-friendly chatting experience. ChatApp features a sidebar navigation, conversation list, chat window, online status indicators, and a message input area.

## Project Preview

![ChatApp Preview](src="./image/image.png")

## Features

- **Modern UI Design** – Clean layout with a professional look.
- **Chat Sidebar** – Quick navigation between Chats, Contacts, and Settings.
- **Conversation List** – View contacts, profile pictures, last messages, and timestamps.
- **Real-Time Chat Interface Design** – Display sent and received message bubbles.
- **Online Status** – Show users' online availability.
- **Message Input** – Text input area for composing messages.
- **Quick Access Menu** – Starred Messages, Archived, and Blocked sections.
- **Chat Controls** – Call, video call, and dark mode icons.
- **User Profile Section** – Display the current user's profile and status.
- **Responsive Design** – Designed with usability and readability in mind.
